# Deutsch Trainer

A free, browser-based German trainer: vocabulary from A1 to B2 plus technical word lists, grammar topics, C-tests, and audio pronunciation.

**Use it here:** https://shrinitlambodari1998-cyber.github.io/deutsch-trainer/

No install or account needed. Progress is saved in your browser.

## Run locally

Download this repo and open `index.html`, or serve the folder with any static server (for example `python3 -m http.server`) so the audio files load.
